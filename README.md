# 채소팜 가격비교 V2

채소팜의 네이버 판매가격과 사용자가 직접 저장한 경쟁사 가격을 비교하는 Streamlit + Render 프로그램입니다.

## 현재 동작 방식

- **우리(채소팜) 가격**: 네이버 커머스 API에서 실행할 때마다 최신 가격 조회
- **경쟁사 가격**: 관리자 화면에서 직접 일괄 입력하여 DB에 저장
- **경쟁사 가격 저장 즉시 반영**: 최신 실행 결과의 경쟁사 가격 부분을 바로 갱신하여 `app`과 `실행 결과`에 표시
- **Cron**: 우리 가격만 새로 조회하고, 경쟁사 가격은 마지막 저장값을 그대로 사용
- **경쟁사 URL 직접 조회/크롤링**: 사용하지 않음

## 검색상품설정

`검색상품설정`에서 상품 ID와 검색어를 함께 관리합니다.

1. 상품 ID가 있으면 상품 ID를 먼저 찾습니다.
2. 상품 ID가 없거나 매칭되지 않으면 검색어로 다시 찾습니다.
3. 둘 다 실패하면 우리 가격을 빈칸으로 표시합니다.

상품 ID는 채널 상품번호, 원상품번호, 판매자 관리코드를 사용할 수 있습니다.

## 경쟁사 가격 일괄 입력

경쟁사 가격 입력 화면을 열면 등록된 모든 상품과 경쟁사 쇼핑몰의 **현재 최신 저장값이
큰 메모장 형태로 자동 표시**됩니다. 가격 숫자를 클릭하면 해당 숫자만 자동 선택되므로,
기존 숫자를 먼저 지우지 않고 바로 새 가격을 입력할 수 있습니다. 가격을 건드리지 않으면
기존 가격이 그대로 저장됩니다. `Ctrl+Enter`(Mac은 `Command+Enter`)로도 저장할 수 있습니다.

상품명 앞 `*`는 선택 사항이며, 숫자 가격을 입력할 때 `-`도 선택 사항입니다.

```text
로케트
우리 - 40,000
그린팜 55,000
야채왕 - 55,000
야채이야기 - 55,000
쉐프의정원 33,000

바질
그린팜 45,000
야채왕 50,000
야채이야기 -
```

- `우리 - 가격` 줄은 저장하지 않습니다.
- 경쟁사 가격은 단축 입력을 지원합니다: `7` → `7,000원`, `15` → `15,000원`, `135` → `13,500원`, `7500` → `7,500원`.
- `7,500`, `13,500`, `13,550`처럼 쉼표를 넣어 정확히 입력한 가격은 후처리 없이 그대로 사용합니다.
- 입력한 경쟁사 값만 수정합니다.
- 입력하지 않은 기존 경쟁사 값은 유지합니다.
- `야채이야기 -`처럼 가격을 비우면 해당 가격을 삭제합니다.
- 상품 사이 빈 줄은 없어도 됩니다.
- 일부 상품이나 일부 경쟁사만 입력해도 됩니다.

## 페이지 구성

1. app
2. 실행 결과
3. 검색상품설정
4. 경쟁사 가격 입력
5. 가격 규칙
6. 쇼핑몰 설정
7. 프로그램 설명서

## Render Cron

`render.yaml`의 `50 22 * * *`는 UTC 기준이며, 한국시간(Asia/Seoul, UTC+9)으로 **매일 오전 7시 50분**에 실행됩니다.
Cron은 `python cron_entry.py`를 실행하며 결과를 텔레그램으로 발송합니다.

## 환경 변수

- `DATABASE_URL`
- `RELAY_BASE_URL`
- `RELAY_SHARED_TOKEN`
- 또는 직접 네이버 API 연결 시 네이버 커머스 API Client ID/Secret
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
