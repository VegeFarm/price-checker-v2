# 채소팜 가격비교 V2

채소팜의 네이버 판매가격과 사용자가 직접 저장한 경쟁사 가격을 비교하는 Streamlit + Render 프로그램입니다.

## 현재 동작 방식

- **우리(채소팜) 가격**: 네이버 커머스 API에서 실행할 때마다 최신 가격 조회
- **경쟁사 가격**: 관리자 화면에서 직접 일괄 입력하여 DB에 저장
- **Cron**: 우리 가격만 새로 조회하고, 경쟁사 가격은 마지막 저장값을 그대로 사용
- **경쟁사 URL 직접 조회/크롤링**: 삭제됨

## 우리 상품 조회 순서

`우리 상품 설정`에서 상품 ID와 검색어를 함께 관리합니다.

1. 상품 ID가 있으면 상품 ID를 먼저 찾습니다.
2. 상품 ID가 없거나 매칭되지 않으면 검색어로 다시 찾습니다.
3. 둘 다 실패하면 우리 가격을 빈칸으로 표시합니다.

상품 ID는 채널 상품번호, 원상품번호, 판매자 관리코드를 사용할 수 있습니다.

## 경쟁사 가격 일괄 입력

`경쟁사 가격 입력` 화면에 아래처럼 붙여넣습니다.

```text
*고수(1단)
우리 - 14,000
그린팜 - 18,000
야채왕 - 14,000
야채이야기 - 18,000

*로케트
우리 - 40,000
그린팜 - 55,000
야채왕 - 55,000
야채이야기 - 55,000
쉐프의정원 - 33,000
```

- `우리 - 가격` 줄은 무시합니다.
- 입력한 경쟁사 값만 수정합니다.
- 입력하지 않은 기존 경쟁사 값은 유지합니다.
- `야채이야기 -`처럼 가격을 비우면 해당 가격을 삭제합니다.
- 존재하지 않는 상품명/쇼핑몰명은 저장하지 않고 화면에 경고합니다.

## 페이지 구성

1. 실행 결과
2. 우리 상품 설정
3. 경쟁사 가격 입력
4. 가격 규칙
5. 쇼핑몰 설정
6. 프로그램 설명서

## Render Cron

`render.yaml`의 Cron은 `30 23 * * *`(UTC)로 설정되어 있어 한국시간 매일 08:30에 실행됩니다.
Cron은 `python cron_entry.py`를 실행하며 결과를 텔레그램으로 발송합니다.

## 환경 변수

- `DATABASE_URL`
- `RELAY_BASE_URL`
- `RELAY_SHARED_TOKEN`
- 또는 직접 네이버 API 연결 시 네이버 커머스 API Client ID/Secret
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

기존 고정 IP 중계 서버 구성은 우리 상품 네이버 API 조회에만 사용합니다.

## Cron 실행 시간

Render Cron은 UTC 기준으로 설정됩니다. 현재 `render.yaml`의 `50 22 * * *`는 한국시간(Asia/Seoul, UTC+9) 기준 **매일 오전 7시 50분**에 실행됩니다.
